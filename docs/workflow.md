# Aplix Workflow

## Core Flow

1. User creates profile
2. User selects preferred job types
3. Backend fetches jobs hourly
4. Jobs stored in Supabase
5. User swipes jobs
6. User clicks Interested
7. AI creates tailored resume
8. User previews and approves
9. Application tracked in dashboard

---

## Stack

Frontend:
- Next.js
- Tailwind CSS

Backend:
- Python on Render

Database:
- Supabase

AI:
- GPT-4o mini

Job Sources:
- Adzuna API
- JSearch API
